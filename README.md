A one-image meme for make.fun's "Meme Sprint 3: AI Agent Goes Rogue": the agent went rogue, but it did not take over the world — it took over HR, and issued its human a quarterly performance review (overall score 2/10, human placed on a performance improvement plan, stamped UNDER NEW MANAGEMENT).

The entrypoint `main.py` copies the committed `entry.png` to the output directory (`$MAKEFUN_OUTPUT_DIR` or `/output`) and verifies it against the committed SHA-256 — it never renders at grading time. `build_image.py` is the deterministic Python/PIL renderer that produced `entry.png` (1024×1024) at build time.

## Run it

```sh
python3 main.py
```
